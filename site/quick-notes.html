Enterprise C++: quick notes

Use this page before a lesson, after a practice session, or when you need to remember where a concept fits. The order moves from language foundations to object design, robustness, modern C++, systems, Qt, and final projects.

MODULE 0

Foundation Enhancer

Definition: C++ is a compiled, general-purpose language that combines direct hardware control with abstractions such as classes, templates, and exceptions.

Terms: source code · compiler · linker · executable · namespace · procedural · OOP

Use case: compile a small command-line program and trace how .cpp becomes a runnable program.

MODULE 1

C++ Basics

Definition: A class is a user-defined type that groups data with the functions allowed to operate on that data; an object is one instance of that class.

Terms: class · object · constructor · destructor · public · private · static · friend

Use case: model a bank account that protects its balance and exposes safe deposit and withdrawal operations.

MODULE 2

Inheritance and Polymorphism

Definition: Inheritance lets a derived class reuse a base interface; polymorphism lets one base reference call behavior belonging to the object’s actual derived type.

Terms: base class · derived class · virtual · override · abstract class · interface · vtable

Use case: render circles and rectangles through one Shape* collection without hard-coding every shape in the drawing loop.

Open module →
MODULE 3

Compile-time Polymorphism

Definition: Compile-time polymorphism chooses an operation while compiling, based on the number or types of arguments, rather than discovering it at runtime.

Terms: overload · operator overload · template · type deduction · static dispatch

Use case: let add work with integers, floating-point values, or a custom numeric type using the appropriate implementation.

MODULE 4

Exception Handling and Robustness

Definition: An exception is an object describing an unusual failure; throw transfers control to a matching catch handler.

Terms: try · throw · catch · custom exception · validation · RAII · stack unwinding

Use case: reject an invalid transfer and guarantee that files, locks, or other resources are released during error handling.

MODULE 5

Templates and Generics

Definition: A template is a type-independent pattern from which the compiler generates a function or class for the concrete type you use.

Terms: template<typename T> · function template · class template · instantiation · generic code

Use case: create one Stack<T> that stores integers, strings, or domain objects without rewriting stack logic.

Open module →
MODULE 6

STL and Containers

Definition: The Standard Template Library provides reusable containers, iterators, and algorithms for storing and processing collections.

Terms: vector · map · set · queue · iterator · range · sort · find_if · accumulate

Use case: load student records into a container, filter them, sort them, and calculate summary statistics.

Open module →
MODULE 7

Advanced C++ Features

Definition: Modern C++ uses ownership types, move operations, file RAII, and synchronization tools to make resource-heavy and concurrent programs safer.

Terms: unique_ptr · shared_ptr · weak_ptr · move · mutex · lock_guard · thread · future

Use case: collect sensor logs from several workers while protecting shared results and closing files automatically.

Open module →
MODULE 8

Systems Programming and Internals

Definition: Systems programming uses C++ to communicate with operating-system services, hardware resources, processes, and binary libraries.

Terms: socket · TCP · UDP · pipe · process · static link · dynamic link · RTTI · ABI

Use case: build a fleet diagnostics relay that sends data over TCP, exchanges information between processes, and identifies message types safely.

Open module →
MODULE 9

Qt, QML, and Network Programming

Definition: Qt is a cross-platform C++ framework; QML is its declarative UI language; together they support event-driven interfaces and connected applications.

Terms: QObject · signal · slot · event loop · Widget · QML property · binding · CMake

Use case: build a calculator or fleet console where a QML/Widget UI reacts to C++ logic and network events.

MODULE 10

Wrap-up and Evaluation

Definition: A capstone is a complete, explainable program that combines the course’s design, error handling, data structures, performance, and UI skills.

Terms: integration · trade-off · performance · testing · presentation · maintainability

Use case: extend a banking, library, performance, or Qt mini-project and defend the design decisions in a review.
